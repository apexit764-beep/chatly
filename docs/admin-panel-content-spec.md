### الصفحة 1️⃣ — نظرة عامة `/dashboard`

**العنوان:** `نظرة عامة`
**الوصف الفرعي:** `آخر تحديث: منذ لحظات · {تاريخ اليوم}`
**الفلتر العلوي:** اليوم / 7 أيام / 30 يوم / 90 يوم / سنة

#### القسم أ — بطاقات KPI الرئيسية (6 بطاقات في صفّ واحد lg، 2 columns على mobile)

| البطاقة | القيمة | المقارنة | الأيقونة |
|---|---|---|---|
| الإيرادات الشهرية (MRR) | ٤٥,٦٧٨ ر.ع | ▲ +12.4% مقابل الشهر الماضي | 💰 DollarSign |
| الإيرادات السنوية (ARR) | ٥٤٨,١٣٦ ر.ع | ▲ +18.2% مقابل الفترة السابقة | 📈 TrendingUp |
| العملاء النشطون | ١٢٤٧ | ▲ +٤٧ عميل جديد هذا الشهر | 👥 Users |
| معدّل الإلغاء (Churn) | 2.3% | ▼ -0.4% مقابل الشهر الماضي | 📉 TrendingDown |
| متوسط الإيراد لكل عميل (ARPU) | ٣٦.٦٢ ر.ع | ▲ +٢.١% | 🎯 Target |
| قيمة العميل مدى الحياة (LTV) | ١٥٩٢ ر.ع | ▲ +5.3% | 💎 Gem |

#### القسم ب — الرسوم البيانية (صفّان)

**الصفّ الأول (2 بطاقات — 2 columns):**

**1. نمو الإيرادات (LineChart كبير — 2/3 من العرض)**
- **العنوان:** `نمو الإيرادات`
- **الأزرار العلوية:** MRR | New MRR | Expansion | Churn (يبدّل بين خطوط)
- **المحاور:** الأشهر على X، المبلغ بالريال العماني على Y
- **Empty state:** `لا توجد بيانات كافية لعرض الرسم — انتظر تسجيل أول اشتراك`

**2. توزيع الباقات (DoughnutChart — 1/3 من العرض)**
- **العنوان:** `توزيع العملاء على الباقات`
- **البيانات:** Starter/Pro/Business/Enterprise + الأعداد والنسب
- **Legend:** بجانب الرسم أو تحته

**الصفّ الثاني (2 بطاقات متساوية):**

**3. البلدان الأعلى إيراداً (BarChart أفقي)**
- **العنوان:** `أعلى 5 دول من حيث الإيرادات`
- **البيانات:** علم البلد + الاسم + المبلغ

**4. حالة الاشتراكات (Doughnut + جدول جانبي)**
- **العنوان:** `توزيع حالات الاشتراكات`
- **البيانات:** نشط، تجريبي، متأخّر السداد، معلّق، ملغى

#### القسم ج — بطاقتان جنباً إلى جنب

**5. آخر العملاء المضافين (جدول مصغّر)**
- **العنوان:** `آخر ٥ عملاء`
- **الأعمدة:** الأفاتار + الاسم | البلد | الباقة | التاريخ | زر ↗
- **الفوتر:** `عرض كل العملاء ←` (رابط)

**6. آخر النشاطات (Live Activity Feed)**
- **العنوان:** `آخر النشاطات`
- **العناصر:** كل عنصر بصيغة:
  - `✨ عميل جديد: {اسم الشركة} · منذ {timeAgo}`
  - `💰 اشتراك جديد: {الاسم} → باقة {الباقة} · منذ {timeAgo}`
  - `📈 ترقية: {الاسم} من Pro إلى Business · منذ {timeAgo}`
  - `⚠️ فاتورة فشلت: {الاسم} — {المبلغ} · منذ {timeAgo}`
  - `😔 إلغاء: {الاسم} · منذ {timeAgo}`

#### القسم د — التنبيهات والإجراءات

**7. تنبيهات تحتاج انتباهك (بطاقة تحذيرية)**
- **العنوان:** `يحتاج انتباهك`
- **العناصر (كل واحد كـ chip قابل للنقر):**
  - `🔴 {عدد} فواتير فشلت — {المبلغ الإجمالي}`
  - `🟡 {عدد} اشتراكات متأخّرة السداد`
  - `🟠 {عدد} تجريبيون سينتهون خلال 3 أيام`
  - `🟢 {عدد} تذاكر دعم مفتوحة`

**8. صحة النظام (بطاقة موجزة)**
- **العنوان:** `صحة النظام`
- **العناصر:** 4 أيقونات ملوّنة صغيرة
  - API: 🟢 مستقر
  - قاعدة البيانات: 🟢 مستقر
  - بوابة الدفع: 🟢 مستقر
  - WhatsApp API: 🟡 بطيء
- **الفوتر:** `عرض التفاصيل ←`

#### الحالات الفارغة (Empty States)
- **إذا لا يوجد أي عميل بعد:**
  - أيقونة كبيرة + `مرحباً بك في Qhub Admin — لم يسجّل أي عميل بعد`
  - زر: `دعوة أول عميل`

### الصفحة 2️⃣ — العملاء `/clients`

**العنوان:** `العملاء`
**الوصف الفرعي:** `إدارة كل العملاء المشتركين في المنصّة`

#### شريط الإجراءات العلوي
- زر رئيسي: `+ إضافة عميل`
- زر ثانوي: `↓ تصدير CSV`
- زر ثانوي: `⚙️ عرض الأعمدة` (customize columns)

#### شريط الفلاتر
- بحث: `ابحث بالاسم، البريد، الجوال، اسم الشركة…`
- Chips قابلة للاختيار السريع:
  - `الكل ({العدد})` | `تجريبي ({العدد})` | `نشط ({العدد})` | `متأخّر ({العدد})` | `معلّق ({العدد})` | `ملغى ({العدد})`
- Dropdown: `كل الباقات` → Starter/Pro/Business/Enterprise
- Dropdown: `كل الدول`
- Dropdown: `ترتيب حسب` → الأحدث / الأقدم / الأعلى إيراداً / الاسم أ-ي

#### StatCards علوية (4 بطاقات)
| البطاقة | القيمة |
|---|---|
| إجمالي العملاء | ١٢٤٧ |
| نشطون هذا الشهر | ١١٨٩ |
| مشتركون جدد هذا الشهر | ٤٧ |
| قيد التجربة | ٢٣ |

#### الجدول الرئيسي

**الأعمدة:**
| العمود | العرض | المحتوى |
|---|---|---|
| ☐ | ضيق | Checkbox للتحديد المتعدد |
| العميل | 25% | Avatar + `{الاسم}`<br/>`{اسم الشركة} · {البريد}` |
| البلد | 12% | 🇴🇲 عمان |
| الباقة | 12% | Badge ملوّن: `Pro / شهري` |
| الحالة | 10% | Badge: نشط / تجريبي / متأخّر / معلّق / ملغى |
| MRR | 12% | `٣٥.٠٠ ر.ع` |
| آخر نشاط | 12% | `منذ ساعتين` |
| تاريخ التسجيل | 12% | `2026-05-14` |
| ⋮ | ضيق | Actions menu |

**Actions Menu (لكل صف):**
- 👁 عرض التفاصيل
- ✏️ تعديل
- 🔗 فتح لوحة العميل (Impersonate) → يفتح tab جديد مع بانر تحذيري
- 💰 عرض الفواتير
- 🎫 عرض التذاكر
- ⏸ تعليق الاشتراك (يفتح modal لسبب التعليق)
- ▶️ إعادة التفعيل (إذا معلّق)
- 📧 إرسال بريد
- 🗑 حذف نهائي (destructive — يفتح confirmation)

**Bulk Actions (عند تحديد أكثر من صف):**
- شريط علوي يظهر: `تم تحديد {العدد} عميل`
- أزرار: `تصدير المحدّد` | `تعليق` | `إرسال بريد جماعي` | `حذف`

## القسم الخامس: خارطة الملاحة (User Flows)

### 5.1 Flow — إضافة عميل جديد يدوياً
1. `/clients` → زر `+ إضافة عميل`
2. Modal ← ملء الحقول
3. حفظ ← Toast: `تم إنشاء الحساب. أُرسلت بيانات الدخول للعميل.`
4. Redirect: `/clients/:id` (الملف الجديد)

### 5.2 Flow — حل تذكرة دعم
1. `/dashboard` → chip `{عدد} تذاكر مفتوحة`
2. `/support` (فلتر: مسندة لي)
3. اختر تذكرة ← `/support/:id`
4. اقرأ تفاصيل العميل (Sidebar الأيمن)
5. (اختياري) `🔗 فتح لوحته` للفحص
6. اكتب الرد ← أرسل + غيّر الحالة لـ `تم الحل`
7. Toast: `تم إرسال الرد وتحديث الحالة`

### 5.3 Flow — استرداد فاتورة
1. `/finance/invoices` → ابحث عن الفاتورة
2. Actions ⋮ → `استرداد`
3. Modal: `المبلغ الكامل / جزئي` + `السبب` + `تأكيد`
4. إذا > 500 ر.ع: يتطلب موافقة super_admin
5. Toast: `تم إرسال طلب الاسترداد للبوابة`

### 5.4 Flow — إنشاء باقة مخصّصة لـ Enterprise
1. `/plans` → `+ باقة جديدة` → tier: `enterprise`
2. اضبط السعر والحدود
3. حفظ كـ `hidden` (لا تظهر في صفحة الأسعار العامة)
4. `/clients/:id` → الاشتراك → `تعيين باقة مخصّصة`
5. اختر الباقة ← احفظ

## القسم السادس: قواعد التصميم (Design Rules)

- **Padding قياسي للصفحات:** `p-4 lg:p-6 space-y-5 page-fade`
- **Cards:** `rounded-card p-5`
- **StatCards:** استخدم `<StatCard>` من `@components/ui`
- **الفواصل بين الأقسام:** `space-y-5` أو `space-y-6`
- **Grid:** `grid grid-cols-2 lg:grid-cols-4 gap-4` (للـ stats)
- **RTL:** كل شيء يدعم `dir="rtl"` تلقائياً — استخدم `start`/`end` بدلاً من `left`/`right`
- **الأيقونات:** من `lucide-react` بحجم `h-4 w-4` أو `h-5 w-5`
- **الألوان الدلالية:** `text-primary`, `text-success`, `text-warning`, `text-danger`, `text-info`
- **Dark mode:** لكل لون فاتح، يجب وجود مقابل `dark:*`
- **Animation:** `transition-colors` للـ hovers, `page-fade` عند التحميل
